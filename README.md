# Marico Limited — Financial Due Diligence

## Project Overview
This project is an Excel-based financial due diligence case study of Marico Limited. It focuses on reviewing historical financial information, calculating key financial ratios, comparing year-over-year performance, and identifying areas that require further investigation.

## Objectives
- Review historical financial performance.
- Analyse revenue, profitability, assets, liabilities, and equity.
- Evaluate liquidity and operating cash flow.
- Identify preliminary financial risk indicators.
- Present findings in a structured Excel workbook.

## Tools Used
- Microsoft Excel
- Financial statement analysis
- Ratio analysis
- Data validation and comparison

## Project Structure
- `Financial_Due_Diligence/01_Source_Data/` — Source annual report.
- `Financial_Due_Diligence/02_Excel_Workbook/` — Financial analysis workbook.
- `Financial_Due_Diligence/03_Final_Report/` — Reserved for the final report.

## Important Note
This is a preliminary educational case study, not an audit or investment recommendation. Financial figures and observations must be verified against the company's official consolidated financial statements and relevant notes before conclusions are treated as final.
